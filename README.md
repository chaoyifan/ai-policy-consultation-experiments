# Experiment Websites

Static sites for a series of experiments, published with GitHub Pages.

## Naming convention

- `s01`: study 1
- `g01`: group 1
- `a`: condition/site code A

Current site: `s01/g01/a/`

Add future sites using the same neutral directory structure, for example `s01/g02/a/` or `s02/g01/b/`.
